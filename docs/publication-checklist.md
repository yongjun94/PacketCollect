# 공개 전 확인 목록 / Publication checklist

**프로젝트 소개 문서**, **소스 공개**, **실행 파일 재배포**는 서로 다른 결정입니다. 공개용 소개 초안을 준비했다고 나머지가 승인되는 것은 아닙니다.

## 소개 문서

- [x] 목적·구조·지원 범위를 설명하는 한국어/영문 초안 준비
- [x] 고객 화면 대신 가상 데이터의 UI 도식 사용
- [x] Fiddler Classic 비상업적 무료 사용과 상업적 전환 정책 구분
- [x] 미검증 기능·라이선스 검토 상태 표시
- [ ] 공개 주체의 최종 표현·권리 검토

## 소스 저장소 공개

- [ ] 자체 코드의 권리자·업무상 공개 승인 확인
- [ ] 자체 코드에 적용할 LICENSE 결정 및 의존성 예외/고지 분리
- [ ] 현재 파일뿐 아니라 Git 전체 이력의 비밀정보·고객 데이터·업무 정보 검사
- [ ] fixture TLS 키가 실제 배포 CA 키와 다름을 확인하고 테스트 전용으로 명시
- [ ] 네이티브·third-party source의 재배포 조건 확인

현재 작업은 저장소를 public으로 전환하거나 임의의 MIT/Apache 라이선스를 부여하지 않습니다.

## 실행 파일 배포

- [ ] 플랫폼별 실제 파일의 native/transitive SBOM 확정
- [ ] UNRESOLVED 항목 해소 및 모든 필요한 전문·저작권·NOTICE 포함
- [ ] LGPL/MPL 등 적용 소스 제공과 빌드/교체/재결합 조건 충족 방법 확인
- [ ] 자체 앱의 사용/재배포 조건과 third-party 권리 간 충돌 확인
- [ ] 변경된 패키지의 빌드·캡처·Export·복구 회귀 테스트
- [ ] OSS/법무 검토 결과와 허용 배포 대상을 문서화

코드 서명·공증은 실행 신뢰와 업데이트를 위한 별도 과제입니다. 서명이 있어도 라이선스 준수가 자동으로 증명되는 것은 아니며, 라이선스 준수가 확인되어도 OS 실행 정책을 자동 통과하는 것은 아닙니다.
