# Windows 수동 검증 기록 양식 — 현재 모두 미실행

- OS/build/architecture:
- Flutter/Python/Visual Studio versions:
- unsigned build SHA256:
- Python/Flutter 없는 clean VM에서 실행:
- HTTP/HTTPS/HTTP2/binary/gzip/duplicate header:
- CA fingerprint before/install/status/remove/기존 인증서 불변:
- 프록시 원상태/apply/normal exit/kill/restart/recover/external changes:
- Fiddler Classic 정확한 버전, generated SAZ open, reference SAZ comparison:
- Chrome 정확한 버전, DevTools HAR Import:
- selected/all/empty/partial exports:
- 장시간/대용량/메모리/세션 수/측정 도구:
- license/native dependency/SBOM/security review:

표시 항목마다 pass/fail, 재현 절차, actual result, 산출물 hash를 기록합니다. 스크립트 존재나 ZIP 구조 검증만으로 수동 항목을 pass 처리하지 않습니다.
